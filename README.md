# shellbacklabs.app

The Shellback Labs website, served by GitHub Pages at https://shellbacklabs.app.

Plain HTML and CSS: no framework, no JavaScript, no analytics, no trackers. Light and dark follow the reader's settings.

| Page | Path |
| --- | --- |
| Home | `index.html` |
| Shipshape privacy policy | `shipshape/privacy/index.html` |
| Shipshape support | `shipshape/support/index.html` |

`CNAME` sets the custom domain; `.nojekyll` tells Pages to serve the files as they are.

The Shipshape app links to the privacy and support pages (`Shipshape/AppLinks.swift` in the Shipshape repo). If a path here changes, change it there too.
